# 🎓 Student Habit Tracker

## 📌 Project Overview

This is an Android mobile application designed to help students manage their academic activities and daily habits in one place.

The application combines student record management, attendance tracking, study scheduling, and daily habit tracking to help students improve productivity, discipline, and time management.

The app is developed using Kotlin and Android Studio, with local data storage using Room Database (SQLite).

---

## ⚙️ Technologies Used

- Kotlin — Application development and core logic
- Android Studio — Development environment
- XML — User interface design
- Room Database — Local data storage
- SQLite — Database engine
- RecyclerView — Displaying list-based data
- Material Design — UI components

## 🛠️ How It Works

The application follows a simple flow:

User  
↓  
Student Profile  
↓  
Attendance / Study Schedule / Habits  
↓  
Room Database  
↓  
Stored & Retrieved Data  
↓  
Displayed in Application

The application uses Room Database to store information locally on the device. RecyclerView is used to display list-based data.

---

## 🏗️ Project Structure

The application follows a modular approach with separate:

- UI Layer — Screens and user interaction
- Logic Layer — Application functionality
- Data Layer — Database and data management

This structure makes the application easier to maintain and extend.
